# Bases de datos desde cero

Curso interactivo de bases de datos y SQL en una sola página: conceptos, comandos esenciales, errores y excepciones comunes, preguntas por capítulo, 24 ejercicios con corrección automática, laboratorio SQLite en el navegador (sql.js) y examen final.

Abre `index.html` en cualquier navegador o visita la versión publicada en GitHub Pages.
